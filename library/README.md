# Library: everything found so far, by category

Each category has an **index** (`README.md`) listing its topics with the current verdict. Each topic has **one
living page** with the verdict at the top, which is updated whenever new research lands. The raw research notes
and studies sit underneath, linked from each page.

**How to read a verdict.** Confidence runs **Strong** (many good trials agree) → **Moderate** → **Limited** →
**Very limited / unknown**. "Draft" means it hasn't been through the independent audit yet.
